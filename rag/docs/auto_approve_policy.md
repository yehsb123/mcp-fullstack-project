# 자동 승인 정책

## 목적
반복적이고 명확한 권한 신청은 사람의 개입 없이 Agent가 자동으로 승인하여 업무 효율을 높인다.

## 자동 승인 조건
아래 조건을 **모두** 충족하는 경우에만 자동 승인이 가능하다.

### 필수 조건
1. 요청 리소스의 등급이 **Level 1 (일반)**일 것
2. 신청자의 소속 부서와 리소스의 소속 부서가 **동일**할 것
3. 신청자의 재직 상태가 **정규직** 또는 **계약직**일 것 (인턴, 외부 협력사 제외)

### 추가 자동 승인 가능 케이스
- 기존에 동일 리소스에 대한 권한을 보유했던 이력이 있고, 만료 후 **30일 이내** 재신청하는 경우
- 팀장이 사전에 **일괄 승인 목록**에 등록해둔 리소스인 경우

## 자동 승인 불가 케이스
- 신청자가 수습 기간(입사 후 3개월) 중인 경우
- 최근 6개월 내 보안 위반 이력이 있는 경우
- Level 2 이상 리소스는 자동 승인 대상에서 제외
- 동시에 3건 이상의 권한 신청이 접수된 경우 (이상 행위 의심)

## 자동 승인 후 처리
- 권한 유효 기간: 180일 (자동 설정)
- 승인 사실을 신청자와 팀장에게 알림 발송
- audit_logs에 "자동 승인" 사유와 충족 조건 기록

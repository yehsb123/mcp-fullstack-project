# 보안 위반 및 권한 회수 정책

## 목적
권한 남용, 보안 위반 발생 시 권한 회수 및 제재 기준을 정의한다.

## 보안 위반 유형

### 경미한 위반
- 권한 범위를 초과한 데이터 조회 시도 (차단됨)
- 타인의 계정으로 접근 시도 (차단됨)
- 권한 만료 후 연장 없이 접근 시도

**조치**: 경고 1회 + 해당 리소스 접근 로그 기록

### 중대한 위반
- 고객 데이터를 외부로 반출 (이메일, USB, 클라우드 등)
- 권한을 이용해 업무 외 목적으로 데이터 조회
- 타인에게 본인 접근 권한 공유 (비밀번호, 토큰 등)

**조치**: 해당 리소스 권한 즉시 회수 + 보안팀 보고 + 6개월간 Level 2 이상 신청 제한

### 심각한 위반
- 고객 개인정보 유출 (의도적/비의도적 불문)
- 시스템 접근 권한을 이용한 데이터 변조
- 보안 시스템 우회 시도

**조치**: 전체 시스템 접근 권한 즉시 회수 + 보안팀 + 인사팀 + 법무팀 보고 + 징계 절차 진행

## 권한 자동 회수 조건
| 조건 | 회수 범위 | 시점 |
|------|----------|------|
| 퇴직 처리 | 전체 권한 | 퇴직일 당일 자동 |
| 부서 이동 | 이전 부서 리소스 권한 | 이동일로부터 7일 후 |
| 권한 만료 | 해당 리소스만 | 만료일 자동 |
| 휴직 (30일 이상) | Level 2 이상 권한 | 휴직 시작일 |
| 보안 위반 (중대) | 해당 리소스 | 즉시 |

## 보안 위반 이력 관리
- 모든 보안 위반은 audit_logs에 기록
- 보안 위반 이력은 **24개월간 유지**
- 이력이 있는 사용자의 Level 2 이상 신청 시 Agent가 자동으로 보안팀 에스컬레이션
- 12개월 내 경미한 위반 3회 이상 → 중대한 위반과 동일하게 처리

## Agent의 보안 위반 확인 절차
1. 권한 신청 접수 시 신청자의 보안 위반 이력 자동 조회
2. 위반 이력이 있으면 해당 위반 유형과 발생일을 판단 근거에 포함
3. 중대/심각한 위반 이력이 있으면 무조건 보안팀 에스컬레이션
4. 경미한 위반만 있으면 정상 판단 절차 진행 (단, 로그에 이력 참조 사실 기록)

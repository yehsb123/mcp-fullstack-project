# 권한 등급 정책

## 등급 분류

| 등급 | 분류 | 설명 | 예시 시스템 |
|------|------|------|------------|
| Level 1 | 일반 | 업무 수행에 기본적으로 필요한 리소스 | 사내 위키, 공유 폴더, 사내 메신저 |
| Level 2 | 민감 | 고객 정보 또는 재무 정보가 포함된 리소스 | 고객 데이터베이스, 재무 시스템, CRM |
| Level 3 | 기밀 | 인사 정보, 보안 로그 등 극히 제한된 리소스 | 인사 시스템, 보안 로그, 급여 시스템 |

## 등급별 승인 절차

### Level 1 (일반)
- 자동 승인 조건을 충족하면 Agent가 즉시 승인 처리
- 자동 승인 조건을 충족하지 않으면 팀장 승인 필요

### Level 2 (민감)
- 반드시 팀장 승인 필요
- 타 부서 리소스 접근 시 해당 부서장 추가 승인 필요
- 접근 권한 유효 기간: 최대 90일 (연장 시 재신청)

### Level 3 (기밀)
- 반드시 CISO(최고정보보안책임자) 승인 필요
- 접근 사유서 필수 첨부
- 접근 권한 유효 기간: 최대 30일 (연장 불가, 재신청만 가능)
- 접근 로그 실시간 모니터링 대상

## 등급 판별 기준
- 시스템에 고객 개인정보가 포함되어 있으면 최소 Level 2
- 시스템에 급여, 인사 평가 정보가 포함되어 있으면 Level 3
- 위 조건에 해당하지 않으면 Level 1

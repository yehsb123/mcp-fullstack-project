# 부서별 접근 권한 정책

## 목적
각 부서가 업무상 접근 가능한 시스템 범위를 정의하여 최소 권한 원칙을 준수한다.

## 부서별 기본 접근 권한

### 마케팅팀
| 시스템 | 등급 | 접근 범위 | 비고 |
|--------|------|----------|------|
| 사내 위키 | Level 1 | 전체 | 기본 부여 |
| 공유 폴더 (마케팅) | Level 1 | 마케팅팀 폴더 | 기본 부여 |
| CRM | Level 2 | 읽기 전용 | 팀장 승인 필요 |
| 고객 데이터베이스 | Level 2 | 비식별 데이터만 | 팀장 승인 + 사유 필요 |
| 재무 시스템 | Level 2 | 접근 불가 | 타 부서 리소스 |

## 타 부서 리소스 접근 규칙
- 타 부서 소속 리소스에 접근하려면 **해당 부서장의 추가 승인**이 필요하다
- 타 부서 접근은 **Level 2 이상**으로 자동 분류된다 (Level 1 리소스라도)
- 접근 사유를 반드시 명시해야 하며, "업무 참고" 등 모호한 사유는 반려 대상이다

## 신규 입사자 권한
- 입사 첫 날: 사내 위키, 사내 메신저만 부여 (Level 1)
- 수습 기간(3개월) 중: Level 1 리소스만 신청 가능
- 수습 종료 후: 부서별 기본 접근 권한 일괄 부여
